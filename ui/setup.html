首次接入指导

先接入自己的邮箱和 AI，测试通过后再开始开发。新安装没有任何客户或发件账号，打开软件不会自动发信。

1. 选择服务并填写自己的授权信息

  1. 打开设置，选择邮箱服务商。软件会填入该服务商的常用 SMTP / IMAP 地址；企业域名请以邮箱管理后台为准。
  2. 填写发件邮箱、发件公司、签名及邮箱授权码。部分服务需要先开启 SMTP / IMAP 或由管理员授权。
  3. 选择 AI 服务，填写自己的 API Key 和模型。订阅聊天产品不一定包含 API 额度；不要把账号登录密码当作 API Key。
  4. 保存配置。邮箱授权码和 API Key 仅交给本机后端保存，不写入 GitHub。
打开接入设置

2. 一键检查已配置的连接

检查邮箱收发登录和 AI 最小请求。不会给客户发送测试邮件，不会开启开发；AI 服务可能计入一次小额调用。

3. 审核首封，再明确开始

确认公司身份、邮箱来源、称呼、客户业务和包装方案。先选择纯文字或效果图模式；保留去重、退订、退信和未知结果保护。测试连接成功不代表邮件进入收件箱。

# User Radar + OutreachPilot 桌面工作台（预览版）

本次发布包含本地 Mac 工作台、官网客户查找、客户保存、邮件开发、回复和问题栏的源码。GitHub 保存开源代码，不托管运行中的邮箱后台。

## 安装

需要 macOS、Python 3.11 或更新版本及 Xcode Command Line Tools。先检查 `python3 scripts/install_workbench.py --check`，再运行 `python3 scripts/install_workbench.py`。首次安装会联网安装 Radar 依赖，并在桌面生成唯一的 `User Radar 工作台.app`。

官网普通读取可直接使用；浏览器后备需要本机 Google Chrome、Node.js，并在安装后的 `~/Library/Application Support/UserRadar/automatic-app` 下执行 `npm install`。AI 自动发现需要已登录的 Codex CLI。邮件 AI 和邮箱账号在界面中配置，本版桌面按钮面向 MTT/GUKA 两个账号；新用户需按这两个账号代号设置，或自行调整 controller。发送前选择“包装业务适配开发（图片可选）”方案。

安装不会复制或删除已有客户数据库、密钥、邮箱配置或发送历史，也不会自动开启发信。升级前停止后台，安装程序发现占用端口会退出。保留已有账号暂停状态。

## 开发流程

逐家发现官网 → 查询 Contact/About 等公开来源 → 保存姓名邮箱或官网公共邮箱 → 固定随机分配给选中账号 → 官网实时复核 → 生成客户相关开发信 → 按账号设置发送。没有真实产品图时可以使用文字方案；没有核实邮箱则暂停该客户，不猜测投递地址。

姓名关联邮箱与公共公司邮箱分开保存。手机和 WhatsApp 仅在来源明确时保留，缺失留空。已回复、退订、退信、未知 SMTP 结果、跨账号去重和七天联系冷却继续生效。历史已发送邮件不会自动循环重发。

## 问题栏

记录失败客户、原始原因和首次时间。其他界面或流程问题可以手动登记，修复后填写解决办法；已解决记录继续保留。点击“重新核验并重试”后重新读取官网，清除过期准备内容，保留原始来源及重试历史。核验通过后按当前账号的自动发送设置处理；重试中不标记解决。SMTP 接受后移入“解决记录”，不等于到达收件箱。已跳过客户仍保留待处理，不通过删除来掩盖问题。

修复包括：Cloudflare 公开邮箱解码、局部冲突链接不污染独立销售地址、限制上下文只影响所在联系块、电话号码与邮箱链接不再错误拼接。

## 隐私与第三方组件

不发布客户库、查询快照、实际邮件、图片、账户密码、API 密钥、扩展配对 token 或本机配置。安装时本机生成扩展身份和配对文件。`radar/chrome-extension/config.js` 为生成文件，不纳入 Git。

原创项目按根目录 LICENSE 授权；第三方组件各自遵循 `radar/third_party/COMPONENTS.txt` 和所在目录 LICENSE，包含独立进程运行的 GPL-2.0 theHarvester 解析器、BSD extruct 和 MIT 邮箱解析器。不能将全部第三方代码宣称为 MIT。

## 验证范围

本机检查：后端单元测试、问题生命周期/重试保护测试、邮箱解析回归测试、前端语法检查、Swift 编译。Mac 桌面功能不宣称已在 Windows/Linux 运行；三平台邮件后端由 GitHub Actions 检查。本版仍是预览源码，其他电脑的全新安装和真实邮箱投递需各自配置后验证。

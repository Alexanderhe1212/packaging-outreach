# User Radar 首次接入与使用指南

1. 安装后打开“接入指导”。账号初始为空，客户资料与邮件历史均由您自己建立。
2. 打开设置，选择邮箱服务商预设；填写企业发件邮箱、公司身份与签名。按服务商后台要求开启SMTP/IMAP，创建应用授权码。部分邮箱需管理员允许，不能由软件绕过。
3. 选择AI服务预设，填写自己的API Key与可用模型。ChatGPT/Claude等聊天订阅不一定包含API额度，具体以服务商账号为准。
4. 保存设置，点击“一键检查邮箱与AI连接”。邮箱检查仅验证收发登录，不发送开发信；AI会发起一次最小请求，服务商可能计费。
5. 未通过时按具体提示修正，不要反复重试错误密码。不要向他人发送授权码，不把凭据提交到GitHub。
6. 先添加一家公司核实，检查官网来源、称呼、具体包装业务和针对性文案。公共商务邮箱称呼公司团队，可请求转交相关负责人。
7. 选择纯文字模式时不生成或附加效果图；选择效果图时必须通过图片一致性检查。
8. 确认准备就绪后才明确开启自动发送。保留去重、退信、退订、回复停止和未知发送结果不重发的保护。

SMTP接受不代表投递到收件箱。客户回复、退信与自动回复应分开看。新跨平台安装包关闭窗口后会停止其自身服务；旧macOS后台版本仍按原方式运行。

安装包不附带发信账号、模型额度、客户数据。首次接入可以自动填入预设地址并检查连接，但邮箱授权与API Key必须由账号所有者提供。
